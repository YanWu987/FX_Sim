# FX_Sim
久留美看完的第二天我打开了 IDE。这样爆仓就不用真花钱了。 外汇 19 对 + 期货 5 个，保证金/强平/盯市/涨跌停，外加生存系统和贷款—— 没有联网，没有真实行情，只有你和你的杠杆。    A single-player FX &amp; futures simulator I built after binge-reading "FX Senshi Kurumi". 19 pairs, 5 futures contracts, margin calls, daily mark-to-market, price limits — plus hunger, thirst and loans. Fully offline. The blow-ups are still real.
